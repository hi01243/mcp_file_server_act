how to run it back up

Your setup runs both the server and the ngrok tunnel under pm2, so start by checking those. Run these in PowerShell from the mcp-workspace folder on your Desktop.

1. Check what’s running

pm2 status

You should see mcp and ngrok both showing online. If either shows errored or stopped, or isn’t listed, that’s the problem.

2. Look at the logs

pm2 logs --lines 50

Look for a crash on mcp (a TypeScript error, or the port already in use). For ngrok, look for an auth or tunnel error.

3. Restart

If both apps are listed:
  pm2 restart all
If they’re missing, which is common after a reboot because pm2 on Windows doesn’t auto-start:
  pm2 start ecosystem.config.cjs
If you changed any .ts files and the server runs from a build, rebuild first with npm run build, then restart.

4. Confirm it’s reachable

Open http://localhost:<your port>/mcp in a browser. “Cannot GET /mcp” is the normal, healthy response.
Open https://abrasive-onboard-tasting.ngrok-free.dev/mcp. You should get the same message. If it fails, the tunnel is down: check pm2 logs ngrok, and note that only one ngrok session can use that static domain at a time.

5. Reconnect Claude
Once the URL responds, go to Settings → Connectors and refresh or reconnect the workspace connector. The tool list can go stale after a restart. Then tell me here and I’ll finish the handoff files.

If it still fails, paste the output of pm2 status and the last lines of pm2 logs, and I’ll help work out what’s wrong.
